# Contribuir com o NEXUS Brasil

1. Defina uma pergunta concreta e uma proposta proporcional à capacidade da equipe.
2. Use fontes públicas verificáveis, com URL, instituição, ano do dado e data de consulta.
3. Distinga fato, hipótese, proposta e resultado. Não transforme anúncio em obra concluída.
4. Registre custo, riscos, responsável, indicador, meta e condição de revisão. Se desconhecidos, use “a definir”.
5. Não submeta dados pessoais, avaliações de membros, documentos internos ou relatos sobre pessoas.
6. Valide com `npm run typecheck`, `npm test`, `npm run build` e `npm run verify`.
7. Abra uma proposta de alteração com problema, comportamento esperado, fontes e verificação. A publicação exige revisão editorial.

O conteúdo público deve estimular diálogo e participação democrática, com linguagem respeitosa e construtiva.
