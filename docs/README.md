# Documentação NEXUS Brasil

O [repositório NEXUS-BRASIL](https://github.com/aldenirfilho/NEXUS-BRASIL) reúne o site e seus documentos. A prévia visual é complementar. Esta organização foi revisada em 08/09/2026.

## Documentos institucionais e modelos

| Documento | Uso |
| --- | --- |
| [Ementa pública](../public/documentos/ementa-nexus-brasil.md) | Identidade, missão, princípios, método, governança e implantação |
| [Código de Conduta](../public/documentos/codigo-de-conduta.md) | Compromissos e convivência |
| [Canvas de projeto](../public/documentos/canvas-projeto.md) | Converter uma ideia em proposta verificável |
| [Pauta de reunião](../public/documentos/pauta-reuniao.md) | Organizar evidências, decisões e próximos passos |
| [Matriz RACI](../public/documentos/matriz-raci.md) | Definir quem executa, aprova, é consultado e é informado |
| [Scorecard de desenvolvimento](../public/documentos/scorecard-desenvolvimento.md) | Modelo em branco para conversa individual e privada |
| [Termo de adesão](../public/documentos/termo-adesao.md) | Minuta para aceite voluntário e validação institucional |
| [Metodologia da autoavaliação](../public/documentos/metodologia-avaliacao.md) | Pontuação, carência, registro e limites do instrumento |

Os arquivos são editáveis em Markdown, um formato de texto que o GitHub apresenta com títulos e tabelas. Use o botão **Download raw file** na página de cada arquivo para salvar uma cópia.

Os modelos estão em branco. Scorecards, termos assinados, resultados de avaliações e outros documentos preenchidos com dados pessoais devem ficar em armazenamento privado com acesso autorizado. Publicar uma minuta não comprova assinatura, aprovação formal ou registro jurídico.
